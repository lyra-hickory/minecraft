## Overview

This is a Minecraft project running on my homelab, self hosted, with DNS setup.


The aim is to focus on getting this Minecraft server production-grade, between security, uptime measures, monitoring, and backup strategies.


### Worlds

I am hoping to expand this to multiple worlds, with the ability to switch between, but for now it is remaining as a single world game.
